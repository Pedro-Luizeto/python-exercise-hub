##  Sobre o projeto

O **Python Exercise Hub** é um projeto desenvolvido com o objetivo de organizar e apresentar uma série de exercícios de Python por meio de um menu interativo executado no terminal.

Este projeto faz parte da minha jornada de aprendizado em programação, com foco na prática dos fundamentos da linguagem, no desenvolvimento do raciocínio lógico e na construção de soluções de forma independente.

##  Objetivos

-  Praticar lógica de programação.
-  Trabalhar com estruturas de repetição.
-  Utilizar estruturas condicionais e `match/case`.
-  Aprimorar a interação com o usuário usando `input()` e `print()`.
-  Desenvolver autonomia na resolução de problemas.
-  Acompanhar minha evolução com Python por meio de projetos práticos.

##  Tecnologias utilizadas

- **Python 3**
- `while` — estrutura de repetição.
- `match/case` — seleção de opções.
- `input()` e `print()` — interação com o usuário.
- `time.sleep()` — pausas entre as mensagens.

##  Exercícios

O menu apresenta os seguintes desafios:

| Opção | Exercício | Dificuldade |
|:---:|---|:---:|
| 01 | Cálculo de idade |  Fácil |
| 02 | Operações matemáticas |  Fácil |
| 03 | Cálculo da média escolar |  Difícil* |
| 04 | Verificador de nota mínima |  Médio |
| 05 | Encerrar o programa | — |

*As dificuldades são classificações pessoais e poderão ser ajustadas conforme meu aprendizado.*

##  Como executar

**1.** Certifique-se de ter o Python 3 instalado.

**2.** Clone este repositório:

```bash
git clone https://github.com/Pedro-Luizeto/python-exercise-hub.git
```

**3.** Entre na pasta do projeto:

```bash
cd python-exercise-hub
```

**4.** Execute o arquivo Python:

```bash
python main.py
```

> **Nota:** substitua `main.py` pelo nome real do arquivo, caso seja diferente.
